During this project, I performed web application reconnaissance against the target environment hosted on nahamstore.thm and identified multiple subdomains, including marketing, stock, and shop portals, using tools such as ffuf and Gobuster. I analyzed exposed web functionalities, administrative interfaces, and user-controlled parameters to map the application attack surface.

I also conducted security testing focused on common web vulnerabilities and successfully identified Cross-Site Scripting (XSS) issues, including reflected and stored XSS vectors. During the assessment, I manipulated HTTP requests, tested input validation mechanisms, and examined application responses to understand how improper sanitization could lead to client-side code execution and exposure of sensitive information.
